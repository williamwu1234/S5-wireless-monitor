# DC-S5 无线监看 v1.0

**给 Panasonic DC-S5 用的手机 / 电脑无线监视器。**

官方 LUMIX Flow 不支持 S5，本项目把它的核心能力补了回来：
实时取景、触摸对焦、拍照录像、AE 锁定 —— **零依赖、不装 App、浏览器直接用**。

- 纯 **Python 3 标准库**，无需 `pip install` 任何东西
- 界面是单个 HTML 页面，手机/平板/电脑均可访问，可「添加到主屏幕」当 App 用
- macOS / Linux 均可运行

> 📖 **详细用法**：[`使用说明.md`](使用说明.md) ·
> **协议细节与实测数据**：[`附_技术参考.md`](附_技术参考.md)

## ⚡ 三步开始

1. **确认网络** —— 相机接入 Wi-Fi（或手机热点），电脑与相机在**同一网络**。
   验证：`ping 192.168.1.131`（换成你的相机 IP）
2. **启动** —— 双击 `启动.command`（macOS），或命令行 `./run.sh 192.168.1.131`
3. **打开浏览器** —— 访问终端打印的 `http://<本机IP>:8080`

```bash
./run.sh <相机IP> [端口] [节奏模式] [帧率]

./run.sh 192.168.1.131                 # 默认 8080 端口、固定 18fps
./run.sh 192.168.1.131 8090            # 换端口
./run.sh 192.168.1.131 8080 fixed 12   # 降至 12fps 省带宽
```

| 参数 | 默认 | 说明 |
|---|---|---|
| 相机IP | `192.168.54.1` | 相机地址（默认值为相机 SoftAP 网关） |
| 端口 | `8080` | 本机 HTTP 端口 |
| 节奏模式 | `fixed` | `fixed`=固定帧率取最新帧；`adaptive`=跟随相机速率（不推荐） |
| 帧率 | `18` | fixed 模式输出帧率（官方 640p 标准） |

## ⚠️ 三条铁律

1. **不要反复重启本服务** —— 每次启动都会重新向相机申请授权，会话正常后就一直用着
2. **不要短时间狂点按钮** —— 相机对控制命令频率敏感，连点会被拒绝一段时间（等几秒即可）；
   工具已内置退避重试与 3Hz 限流
3. **相机提示 `invalid login` 时，只能给相机断电重启**（拔电池 10 秒）

## 🟡 已知限制

| 项 | 说明 |
|---|---|
| **MF 模式下触摸对焦失效** | 相机设计如此，请改用「焦点近/远」按钮 |
| **640×432 是相机的硬上限** | `startstream` 接口只有端口参数、无画质选项。要全画质监看只能走 HDMI + 采集卡 |
| 峰值对焦 / 放大辅助 | 相机分别返回 `err_param` / `err_reject`，未找到准入条件，已从界面移除 |
| 蓝牙（BLE） | 仅用于配对/唤醒，带宽 KB/s 级，**无法提升画质** |

## 🛡 安全说明

本工具**只发送**已验证的常规控制命令：
`camcmd`（拍照/录像/变焦/模式切换）、`camctrl`（触摸对焦/AE锁定）、
`getstate`、`getsetting`、`startstream` / `stopstream`。

**代码内置白名单，永不发送**：固件升级、格式化、重置、关机、配置上传等
任何有副作用或不可逆的命令。
